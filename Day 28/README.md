# 📅 Day 28 – Binary Tree Interview Patterns 🌳

Focused on important **Binary Tree interview patterns** using BFS and recursion.

## 📚 Concepts Covered

* Level Order Traversal (BFS)
* Height / Depth of Binary Tree
* Tree Recursion Pattern
* Queue-based Traversal

## 💻 Problems Solved

### 1. Level Order Traversal ⭐⭐⭐⭐⭐

* Traversed the tree level by level using a **Queue**
* **Time:** `O(n)`
* **Space:** `O(n)`

### 2. Maximum Depth of Binary Tree ⭐⭐⭐⭐⭐

* Used recursion to calculate the height of the tree
* Formula: `1 + max(leftHeight, rightHeight)`
* **Time:** `O(n)`
* **Space:** `O(h)`

### 3. Diameter of Binary Tree ⭐⭐⭐⭐⭐

* Calculated the longest path between two nodes
* Used left and right subtree heights
* Formula: `leftHeight + rightHeight`
* **Time:** `O(n)`
* **Space:** `O(h)`
